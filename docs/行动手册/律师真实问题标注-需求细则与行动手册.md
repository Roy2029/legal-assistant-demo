# 律师真实问题标注 需求细则与行动手册

> 对应 ROADMAP：M2 W15「真实问题集 v1 入评估」
> 数量：50-100 条
> 来源：律师/法务朋友真实工作中被问到的法律问题

---

## 一、为什么做

现在的评估集（qrels_v2）是从法条文本自动合成的，能测检索，但和真人提问有差距：
- 真问题更口语、更模糊、更爱用代词（“这个情况怎么处理”）
- 真问题会混合多个法律点，甚至问得不准
- 真问题才能暴露我们系统的真实短板

所以 M2 需要 50-100 条律师真实问题，作为「真实问题集 v1」，用于检索和端到端问答的回归评估。

## 二、结果要求

| 项 | 标准 |
| --- | --- |
| 数量 | 50-100 条（先做 50 条即可） |
| 覆盖 | 至少覆盖 5 个 query_type |
| 每条 | 有 question + query_type + difficulty + 标注 |
| 文件 | `data/eval/real_questions_v1.jsonl` |
| 脱敏 | 人名/公司名/金额可识别信息假名化 |

## 三、怎么做（行动步骤）

### 第 1 步：收集问题
从这些来源收集律师/法务朋友真实被问到的问题：
- 微信聊天记录 / 咨询记录
- 律师朋友日常答疑
- 自己工作中的法律咨询

复制到 `data/eval/real_questions_v1.jsonl`（模板见下），先只填 question 字段。

### 第 2 步：逐条标注
对每条问题填写：
- `query_type`：factoid / definition / entity_attribute / relation / comparison / constraint / procedural / aggregation / multi_hop / summary（选 1 个）
- `difficulty`：simple（单条法条能答）/ medium（需要跨条或简单推理）/ hard（跨多部法或复杂推理）
- `law_name`：该问题涉及的主要法规全称；不确定写 `null`
- `article_no`：涉及的主要条文号（阿拉伯数字）；不确定写 `null`
- `answer_points`：答案要点，1-3 条即可（用于人工判断回答对不对）
- `source`：来源（如“律师A微信咨询”）

### 第 3 步：质量自检
- [ ] 每条问题都是真人真实会问的（不是法考题目）
- [ ] 没有真实人名/公司名/金额
- [ ] law_name / article_no 都查过原文核验（能查到才填）
- [ ] 50 条覆盖至少 5 个 query_type

### 第 4 步：交付
把 `data/eval/real_questions_v1.jsonl` 发我，我来纳入评估脚本，跑检索和端到端基线。

## 四、模板（data/eval/real_questions_v1.jsonl）

```json
{"query_id": "rq-001", "query": "总包把工程转包给个人，现在实际施工人直接找我们要钱，我们该不该给？", "query_type": "constraint", "difficulty": "medium", "law_name": "最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）", "article_no": "43", "answer_points": ["实际施工人可以起诉发包人", "发包人在欠付工程款范围内承担责任"], "source": "律师A微信咨询"}
{"query_id": "rq-002", "query": "合同里写了逾期付款按日千分之一付违约金，法院会支持吗？", "query_type": "constraint", "difficulty": "medium", "law_name": "中华人民共和国民法典", "article_no": "585", "answer_points": ["违约金过高可以请求调减", "以实际损失为基础判断"], "source": "律师A微信咨询"}
```

## 五、验收标准

- [ ] 50-100 条，覆盖 ≥5 个 query_type
- [ ] 每条均有 query_type / difficulty / answer_points
- [ ] 能查到条文的问题，law_name + article_no 准确
- [ ] 无真实人名/公司名/金额

## 六、常见问题

- **Q：标注难度怎么把握？** 简单 = 翻一条法条就能答；中等 = 需要跨条或简单推理；困难 = 需要多部法或复杂分析。
- **Q：法条号不确定怎么办？** 先写 `null`，把 answer_points 写好，我来补法条并核验。
- **Q：能用法考题冒充吗？** 不行。真实问题集的目的是测真实分布，法考题我们已经有了。
