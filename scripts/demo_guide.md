# M0 Demo 演示脚本（20 分钟）

## 准备
1. 双击 `start_all.bat`；
2. 浏览器打开 http://127.0.0.1:5173；
3. 设置页确认 LLM 已配置（.env 自动加载）。

## 演示路径
1. **知识库问答**（5 分钟）
   - "民法典第32条说了什么？" → 精确法条号 + 引用
   - "民法典第580条" → 精确法条号
   - "实际施工人能否向发包人主张工程款" → 语义检索
   - 右侧 Trace 面板：查看 BM25 分词、dense/BM25 各自召回 chunk
2. **闲聊拦截**（1 分钟）
   - "你好" → PreFilter 拦截并提示
3. **设置页**（3 分钟）
   - 自定义关键词：添加"实际施工人"，重新提问，看 BM25 分词
   - LLM 配置热更新
4. **知识库上传**（5 分钟）
   - 上传一份 docx/md 合同/制度文件
   - 提问该文档相关问题
5. **实务助手**（5 分钟）
   - 选择"案情分析"，输入问题，观察 step→tool→final 流程
   - 选择"案例检索"，观察空态提示（不编造案例）
6. **关闭**：运行 stop_all.bat

## M0 已知限制（演示时说明）
- 实务 skill 为流程桩，深度规则库 M1 建设
- 案例库数据未接入
- 引用点击定位原文 M0 未做
- rerank 关闭（4GB 显卡限制）
